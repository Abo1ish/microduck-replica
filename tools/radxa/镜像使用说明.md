# Radxa Zero 3W · 能开机的 Armbian 卡（镜像使用说明）

这张镜像解决一件事：**Armbian 官方镜像在 Radxa Zero 3W V1.12 上起不来**（灯双闪、永远进不了系统、局域网里找不到），
换上瑞莎自家的引导程序就好了。内核和系统一个字节没改，还是 Armbian 官方的。

镜像烧完开机 1~2 分钟就能用，**不带 WiFi 配置**（公开镜像不方便写别人的 WiFi 密码），板子插电脑的那根 USB 线同时是串口，进去自己连网。

- 适用：**Radxa Zero 3W V1.12**（2024-11 以后出厂、AIC8800D80 WiFi 那批），别的批次见下面第 6 节
- 底包：Armbian 26.2.1 Trixie vendor 内核 6.1.115 minimal（官方原版）
- 为什么会这样、怎么定位的：[踩坑记录](../../踩坑记录.md#软件)

## 1. 跟官方 Armbian 镜像的区别

只改了四处，都是踩出来的：

| 改了什么 | 为什么 |
|---|---|
| 引导程序换成瑞莎 `u-boot-rk2410`（`idbloader.img` @扇区 64、`u-boot.itb` @扇区 16384） | Armbian 配的主线 U-Boot 2025.10 + 2024-01 的内存初始化固件在 V1.12 上起不来；瑞莎是 rk U-Boot 2017.09 + DDR v1.23 + BL31 v1.45 |
| 写 `/boot/extlinux/extlinux.conf` | 瑞莎 U-Boot 走 extlinux，不读 Armbian 的 `boot.scr` |
| 挂 `uart2-m0` 和 `dwc3-peripheral` 两个 overlay，内核控制台放 `tty1` | 前者出 `/dev/ttyS2`（40 脚上的串口，接舵机用），后者让 OTG 口插电脑变成串口；内核日志不再往舵机总线上打 |
| 开 `g_serial` + `ttyGS0` 登录控制台，关掉 `ttyS2` / `ttyFIQ0` 上的登录控制台 | 插电脑就能登录，没网也能救；`agetty` 占着 `ttyS2` 舵机怎么都不通 |

## 2. 烧卡

用 Rufus、balenaEtcher、Armbian Imager 任意一个，8 GB 以上的卡。先校验一下下载对不对：

```powershell
# Windows PowerShell
Get-FileHash .\armbian-26.2.1-zero3w-v1.12-bootfix-20260920.img.xz -Algorithm SHA256
```

```bash
# Linux / macOS
sha256sum armbian-26.2.1-zero3w-*.img.xz
```

跟 release 页面上的 `SHA256` 对得上再烧。Rufus 能直接烧 `.img.xz`，不用自己解压。

## 3. 第一次开机

1. 卡插板子，USB 口（靠中间那个，标 USB 3.0 的）用数据线插电脑。
2. 等 1~2 分钟，电脑设备管理器里会多一个 **COM 口**（USB 串口设备）。用 PuTTY / MobaXterm / 串口助手打开，**115200 8N1**，回车。
3. 登录：用户名 `duck`，密码 `duck1234`（root 密码也是 `duck1234`）。
4. **第一件事改密码**：

```bash
passwd            # 改 duck 的
sudo passwd root  # 改 root 的
```

串口里看不到启动日志是正常的：内核日志被放到 `tty1` 了，串口只给登录用。

## 4. 连 WiFi

板子没有网口，只能 WiFi。登录后按下面这套写（**V1.12 + AIC8800 实测能连的就是这套**，板子上 `/root/先连WiFi.txt` 里有同样的内容）：

```bash
sudo tee /etc/wpa_supplicant/wpa_supplicant-wlan0.conf >/dev/null <<'CONF'
ctrl_interface=DIR=/run/wpa_supplicant GROUP=netdev
update_config=1
country=CN

network={
    ssid="你的WiFi名"
    psk="你的WiFi密码"
    key_mgmt=WPA-PSK
    pairwise=CCMP
    ieee80211w=0
    scan_ssid=1
    priority=10
}
CONF
sudo chmod 600 /etc/wpa_supplicant/wpa_supplicant-wlan0.conf
sudo systemctl enable --now wpa_supplicant@wlan0
ip a show wlan0     # 看有没有拿到 IP
```

拿 IP 靠系统自带的 `/etc/netplan/10-dhcp-all-interfaces.yaml`，不用另外配。

**`pairwise=CCMP` 和 `ieee80211w=0` 这两行别删。** AIC8800 不支持 GCMP-256，路由器开 WPA2/WPA3 混合模式时，
WPA3 那半用 GCMP-256，不写这两行握手直接失败。真连不上就把路由器改成纯 WPA2。2.4G、5G 都能连。

也可以 `sudo nmtui` 图形界面选（系统里装了 NetworkManager）。连不上就回到上面那套，多半还是 WPA3 的问题。

连上以后路由器里找 `radxa-zero3`，之后 `ssh duck@板子IP` 就行，不用再插串口。

嫌麻烦不想每次手动连：用仓库里的做卡脚本，烧卡前就把 WiFi 写进去 ——
[`build-armbian-card.sh`](build-armbian-card.sh)，`card.conf` 里填上 WiFi 名和密码，自己生成一张带网的卡（这张公开镜像就是用同一个脚本、WiFi 留空做的）。

## 5. 舵机串口

`/dev/ttyS2` 已经准备好了（40 脚的 8 号 TX、10 号 RX），登录控制台和内核日志都从上面拿掉了。

注意：**RK3566 的 UART 是全双工 3.3 V 两根线，飞特 / Dynamixel 总线是单线半双工**，中间要加三态缓冲或者转接板，直接飞线是收不到应答的。见[踩坑记录](../../踩坑记录.md#飞线不打-hat-时)。

## 6. 如果你的板子不是这一批

Zero 3W 出过好几批，WiFi 模块从 AIC8800D80 换成过别的（比如移远 FSK960K），**引导程序对不上就一样起不来**，
这张镜像里的瑞莎引导不一定认你那批板子的内存。判断方法：这张卡烧进去还是进不了系统，但**瑞莎官方镜像能起**。

那就用同一招，只是换成**从你自己能启动的那张卡里扒引导**：

```bash
# 在 Linux / WSL 里做。/dev/sdX 换成你那张能启动的官方系统卡（别搞错盘！）
sudo dd if=/dev/sdX of=idbloader.img bs=512 skip=64    count=16320   # 扇区 64 起
sudo dd if=/dev/sdX of=u-boot.itb    bs=512 skip=16384 count=16384   # 扇区 16384 起

# 再写进烧好这张 Armbian 卡的 /dev/sdY
sudo dd if=idbloader.img of=/dev/sdY bs=512 seek=64    conv=notrunc
sudo dd if=u-boot.itb    of=/dev/sdY bs=512 seek=16384 conv=notrunc
sync
```

写完还要保证 Armbian 卡上有 `/boot/extlinux/extlinux.conf`（瑞莎 U-Boot 不读 `boot.scr`）——
这张镜像里已经有了，直接烧这张再覆盖引导就行。

还是不行的话，**先想办法看到启动到哪一步**：接 40 脚上的调试串口（3.3 V USB-TTL，波特率 1500000），
能看到 U-Boot 的输出就知道是卡在内存初始化还是找不到内核。没有 USB-TTL 就在 [issue](https://github.com/fanhao375/microduck-replica/issues) 里说你的板子版本、WiFi 模块型号、卡到哪一步，一起看。

## 7. 来源与许可

- 底包：[Armbian 官方 Radxa Zero 3 镜像](https://www.armbian.com/radxa-zero-3/)，26.2.1 Trixie vendor 6.1.115 minimal，原样使用，GPL 及各自许可
- 引导：瑞莎 [`u-boot-rk2410`](https://radxa-repo.github.io/bookworm/pool/main/u/u-boot-rk2410/) `2017.09-64-39cd993`，取 `idbloader.img` 和 `u-boot.itb`，GPL-2.0
- 改动全部在 [`build-armbian-card.sh`](build-armbian-card.sh) 里，脚本是开源的，可以自己跑一遍复现这张镜像

这张镜像是社区自制的，**跟 Armbian 和瑞莎官方都没关系**，出了问题别去找他们，来这个仓库开 issue。
