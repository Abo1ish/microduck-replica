# 验证记录与范围

## 2026-09-21：公开工程

- Windows x64、Python 3.12.14；使用锁定的 Python 依赖。
- `python -m unittest -q test_imu_bridge test_launcher`：47 项测试通过。覆盖姿态数据解码、固件/地址校验、连接与断流行为、WebSocket 控制、配置验证、演示模式和启动器。
- 真板模式必须显式填写 J-Link 序列号与 DLL 路径；无配置时拒绝连接。演示模式不需要 J-Link。
- 在浏览器打开本次提交的无硬件演示，确认模型成功渲染、页面标记“演示模式 · 非硬件”、姿态角和采样计数持续更新，显示读取速率 20 Hz。
- 固件主机测试复测通过：协议 106 项、IMU 16 个场景、寄存器 14 项、Python 4 项。详见固件目录的验证记录。
- 分享打包使用文件白名单，排除个人配置、虚拟环境、日志和本机调试产物；ZIP 中另生成未填写的配置与文件 SHA-256 清单。
- 本次公开整理不连接硬件，不重新烧录或修改预编译 BIN/HEX。

## 2026-09-20：原开发板记录

STM32G031F8P6 + LSM6DSV16X，J-Link 9.78，SWD 100 kHz。此前约 32 秒内读取 120 次，数据持续有效，采样计数从 1997 增至 5842、IMU 错误计数为 0，调试参考电压约 3.293 V。后台以约 20 Hz 提供姿态数据。这是同一块开发板的记录，不能代替其他板的验证。

配套 BIN 为 11612 字节，SHA-256：

`69bdaea7224900addd6eb5bd28001e26e07073c129383d9c1ece380d2bfce19a`

## 尚未验收

- 新电脑、其他 J-Link 与队友的实物板；完整的实物轴向与网页安装方向逐项核对。
- 长时间稳定性、航向漂移、输入电流、温升和电源质量。
- 飞特 STS 总线地址 56、15 字节协议及 `FeetechIo` 整机运行。附带固件是早期 Dynamixel Protocol 2.0 基线，SWD 网页可用不意味着飞特协议可用。
- 舵机运动、机器人平衡或行走；模型只显示姿态，不是动力学仿真。

J-Link 9.78 在此前实测中建连会重启程序；网页归零仅改变显示参考姿态，不写板上参数。固件自身的测试与构建说明见 [firmware/imu_to_dxl/VALIDATION.md](firmware/imu_to_dxl/VALIDATION.md)。
